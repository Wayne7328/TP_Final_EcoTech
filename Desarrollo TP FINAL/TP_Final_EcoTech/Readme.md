Trabajo Práctico Final - Desarrollo Web y Python

Este repositorio contiene la solución completa para el Trabajo Práctico Final del curso de Programación con Python, organizado en tres ejercicios independientes.

Estructura del Proyecto

TP_Final_EcoTech/
├── ejercicio_1_sensores/   
├── ejercicio_2_productos/
└── ejercicio_3_auditoria_web/


Descripción de los Ejercicios

ejercicio_1_sensores/: Contiene la lógica en Python orientada al procesamiento de datos de sensores. Para ejecutarlo, podés correr el archivo principal:

python ejercicio_1_sensores/main.py


ejercicio_2_productos/: Contiene el desarrollo correspondiente al manejo y gestión de productos.

ejercicio_3_auditoria_web/: Contiene la aplicación web desarrollada con el framework Django para la auditoría y panel de sustentabilidad.

Cómo ejecutar el Ejercicio 3 (Django):

Ingresá a la carpeta del proyecto web en tu terminal:

cd ejercicio_3_auditoria_web/eco_project


Ejecutá el servidor de desarrollo:

python manage.py runserver


Abrí en tu navegador la dirección: http://127.0.0.1:8000/

# Trabajo Práctico Final - Módulo 6: Desarrollo Web, Aplicaciones y Conceptos Avanzados

Repositorio que contiene los ejercicios resueltos correspondientes al Trabajo Práctico Final del curso de Programación con Python.

## Estructura del Proyecto

El proyecto está organizado en la siguiente estructura modular:

* **`TP_Final_EcoTech/`**
  * **`ejercicio_1_sensores/`**: Procesamiento, normalización y análisis estadístico de temperaturas de sensores.
  * **`ejercicio_2_productos/`**: Gestión de productos con POO, validación de stock y exportación a JSON.
  * **`ejercicio_3_auditoria_web/`**: Panel administrativo y aplicación web desarrollada en **Django**.
